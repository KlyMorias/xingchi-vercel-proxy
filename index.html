Xingchi API Proxy

İstekler Vercel Function üzerinden Xingchi API’ye yönlendirilir. Kullanılabilir modeller ve istemci erişimi Xingchi hesabının izinlerine bağlıdır.

OpenAI uyumlu istemciler · Base URL https://klyapi.vercel.app/v1
Anthropic uyumlu istemciler · Base URL https://klyapi.vercel.app

İstemcide proxy erişim anahtarını API key olarak kullan. Xingchi anahtarını yalnızca Vercel ortam değişkenlerinde sakla; tarayıcı koduna veya bu sayfaya ekleme.

Desteklenen yollar: /v1/models, /v1/messages, /v1/chat/completions ve /v1/responses.
